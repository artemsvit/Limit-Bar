# Limit Bar 1.1.3

A Codex CLI compatibility fix and tighter menu bar spacing.

## What's new

- Fixed Codex usage failing to load on newer Codex CLI installs that dropped support for an approval-flag value Limit Bar relied on.
- The menu bar's per-provider percentage now sits right next to its dot instead of leaving a fixed gap sized for a 3-digit value, and the gap before the next provider's dot is no longer padded out the same way.

Requires macOS 15.6 or later.
