# Limit Bar 1.1.5

Seamless in-place limits refresh and skeleton loading state.

## What's new

- **Seamless in-place refresh**: Refreshing connected providers never drops connection status or navigates away to the setup screen.
- **Skeleton loading animation**: While fetching updated limits, balance percentages, progress bars, and reset indicators display smooth pulsing skeleton placeholders instead of blanking or shifting UI elements.
- **Instant result presentation**: Fresh quotas and reset timelines display immediately once data is received, with zero UI jumping.

Requires macOS 15.6 or later.
