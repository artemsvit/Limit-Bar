# Limit Bar 1.1.2

Settings polish and a more honest update check.

## What's new

- Fixed Settings sometimes opening off-screen instead of centered on your display.
- Limit Bar now actually checks for updates every time it starts, not just roughly once a day regardless of how often you relaunch it.
- Each provider card now always shows when it was last updated, so a failed background refresh is visible immediately instead of only after a delay - and it no longer shifts the layout when it appears.
- Fixed a provider icon and title that had drifted out of alignment with the rest of the app.
- Minor spacing polish on the Current and Weekly labels.

Requires macOS 15.6 or later.
