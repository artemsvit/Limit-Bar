Requirements

  • macOS 15.6 or later
  • At least one provider CLI installed and signed in: Codex, Claude Code, or Antigravity

Installing

Download the DMG, drag Limit Bar into your Applications folder, then launch it. Limit Bar lives in the menu bar and has no Dock icon. Open its menu and use the gear button to reach Settings.

Connecting a provider

Limit Bar reads the sessions your provider command line tools have already established, so there is nothing to log into inside the app. If a provider shows Connect or Retry instead of Connected, check that its CLI is installed and authenticated:

  • Claude Code — run claude auth status in a terminal and sign in if needed
  • Codex — make sure the Codex CLI is installed and signed in
  • Antigravity — make sure agy is available on your PATH and signed in

Limit Bar looks for these tools using your normal login shell, so a CLI installed through a version manager should be found the same way your terminal finds it. If a provider stays disconnected, hover its row in Settings to see the exact error.

Notifications

Turn on Usage notifications in Settings to be alerted as a balance drains past each threshold. The defaults are 50%, 25%, and 10%, and each applies to both the current and weekly windows. Use Send a test to confirm macOS is allowing alerts. If nothing appears, check System Settings → Notifications → Limit Bar.

Updating

Limit Bar updates itself through Sparkle. Open Settings and choose Check for Updates. Every update is cryptographically signed and verified before installation. Past changes are listed in the release notes.

Uninstalling

Quit Limit Bar from its menu, then drag the app from Applications to the Trash. If you enabled Start at login, turn it off in Settings first, or remove the entry in System Settings → General → Login Items.

Privacy

Limit Bar collects nothing and sends nothing. The full details are in the privacy policy.
