Privacy Policy

Limit Bar runs entirely on your Mac. It has no account system, no analytics, and no server of its own.

The short version: Limit Bar reads usage information that is already on your computer and shows it in your menu bar. It does not transmit that information anywhere.

What Limit Bar collects

Nothing. Limit Bar has no accounts, no sign-in, no telemetry, no analytics, no advertising, and no crash reporting. The app contains no third-party tracking code.

How usage data is read

To show your remaining balance, Limit Bar runs the provider command line tools that are already installed on your Mac — Codex, Claude Code, and Antigravity — and reads the usage information they report locally.

  • Limit Bar never asks for your provider passwords or API keys
  • It does not read browser cookies or scrape provider websites
  • It uses the sessions those tools have already established

Those command line tools are third-party software. When Limit Bar asks one of them for your usage, that tool may contact its own provider, exactly as it would if you ran it yourself in a terminal. Any such request is governed by that provider's own privacy policy, not this one.

What stays on your Mac

Usage percentages, reset times, and any account or plan label a provider tool reports are held in memory and in standard macOS user preferences on your own computer. This information is never sent to the developer or to any third party. Removing the app removes its use of that data.

Network activity

The Limit Bar app itself makes no network requests. There are only two ways network traffic can result from using it:

  • Software updates. Limit Bar uses Sparkle to check a public update feed hosted on GitHub Releases. As with any web request, GitHub receives standard connection information such as your IP address. Updates are cryptographically signed and the signature is verified before anything is installed.
  • Provider tools. Any request made by the Codex, Claude Code, or Antigravity command line tools themselves, as described above.

You can stop update checks at any time by not using Check for Updates.

Notifications

If you turn on usage notifications, alerts are produced locally by macOS on your own machine. No push notification service is involved and no notification content leaves your Mac.

Children

Limit Bar is a developer utility and is not directed at children. It collects no personal information from anyone, including children.

Changes to this policy

If this policy changes, the updated version will be published on this page with a new effective date. Material changes will also be noted in the release notes.
