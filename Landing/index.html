FAQ

Questions people search before they download.

A quick overview of what Limit Bar does, how it works, and why it is useful if you use Codex or Claude Code every day.

What is Limit Bar?

Limit Bar is a macOS menu bar app for tracking Codex, Claude Code, and Antigravity usage, reset times, and remaining headroom from local sessions.

How does usage tracking work?

The app reads local CLI session data, then shows current and weekly usage windows for each connected provider in a small menu bar interface you can check in a second.

Why use a menu bar AI usage tracker?

Because the decision usually happens fast. You want to know whether you still have room for one more run without opening another dashboard or tab.
