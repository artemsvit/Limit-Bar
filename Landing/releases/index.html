Limit Bar 1.1.0

#

A lighter, quieter app: a narrower menu bar, thresholds you can drag, and far less background work.

Codex Claude Code Antigravity
  • The menu bar shows a coloured dot and percentage per provider, about a third narrower, with fixed slots so it no longer shifts as values change.
  • Hover any provider in the menu bar to see its session and weekly balance.
  • Alert thresholds can be dragged on the scale, and the bands show each alert's territory.
  • Limit Bar refreshes the moment you open the menu, instead of showing values up to three minutes old.
  • Background checks run only when notifications are on, every 15 minutes instead of every 3, and pause while your Mac sleeps.
  • A provider whose refresh failed now says so and shows how old its numbers are.
  • Limit Bar checks for updates on launch, with a switch in Settings to turn that off.
  • Settings uses the same violet accent as this site, and reset times no longer read "Resets in in 4h".
