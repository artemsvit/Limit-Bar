Limit Bar 1.0.6

#

A clearer menu bar for people using more than one AI provider.

Codex Claude Code Antigravity

  • When percentage mode is off, each provider gets its own current and weekly bar pair.
  • Antigravity usage now reads quota data from its current /usage command.
  • Claude Code limit detection and connection messages are more reliable.
  • Settings, notifications, thresholds, update controls, and the app footer were refined.
